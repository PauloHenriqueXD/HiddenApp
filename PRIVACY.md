# Política de privacidade / Privacy policy

**Português**

O HiddenApp não coleta, não guarda em servidores e não envia dados pessoais. Não há telemetria, propaganda
nem contas.

- **Configurações, favoritos, macros e a lista de programas bloqueados** ficam só no seu computador,
  em `%AppData%\HiddenApp\`.
- **Verificação de atualizações:** o programa consulta a API pública do GitHub
  (`api.github.com/repos/PauloHenriqueXD/HiddenApp/releases`) e, se você aceitar atualizar, baixa o
  executável do GitHub. Como em qualquer acesso à internet, o GitHub recebe o endereço IP da conexão.
- **Sugestões e doações:** os botões "Sugestões" e "Apoiar" apenas abrem páginas no seu navegador
  (Google Forms, GitHub, GitHub Sponsors). Nada é enviado sem você preencher e confirmar nessas páginas, e
  o que você enviar segue a política de privacidade do respectivo serviço. O formulário vem preenchido
  apenas com a versão do HiddenApp, a versão do Windows e o idioma.
- **O que o programa muda no Windows:** regras do Firewall do Windows (nome `HiddenApp - ...`), a pasta
  `HiddenAppClones` na raiz dos discos (cópias bloqueáveis) e, se você ativar, a tarefa agendada
  `HiddenApp`. Tudo pode ser desfeito em **Atualizações ▾ → Desinstalar (remover tudo do computador)**.

**English**

HiddenApp does not collect, store on servers or send personal data. There is no telemetry, advertising or
account. Settings, favorites, macros and the blocked list stay on your computer (`%AppData%\HiddenApp\`).
Update checks query the public GitHub API and, if you accept, download the executable from GitHub (GitHub
sees the connection's IP address). The "Feedback" and "Support" buttons only open pages in your browser
(Google Forms, GitHub, GitHub Sponsors); nothing is sent unless you fill in and submit those pages, and the
form is prefilled only with the HiddenApp version, Windows version and language. The program changes
Windows Firewall rules (`HiddenApp - ...`), the `HiddenAppClones` folder and, if enabled, the `HiddenApp`
scheduled task — all of which can be undone with **Updates ▾ → Uninstall (remove everything)**.
