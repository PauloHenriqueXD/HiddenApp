Internet under control, program by program

Blocking uses Windows Firewall rules. It stays in effect even with HiddenApp closed or after restarting the PC, until you allow it again.

Block with one click

Lists open windows with a live preview. Select one and click "Block internet" — or double-click. Open connections are dropped immediately.

Blockable copy

Want two windows of the same browser, only one without internet? HiddenApp opens a copy of the program (taking no space) with its own block. You can have several.

Favorites

Star the programs you block often and control everything right from the icon next to the clock.

Lives in the tray

It can start with Windows, hidden next to the clock, without asking for confirmation every time.

Portuguese, English and Chinese

Follows the Windows language, with dark and light themes. Every button explains what it does when you hover it.

Safe updates

Tells you when there is a new version and only updates if you want. The downloaded file is verified (SHA-256) before it is installed.

Macros: leave the repetitive clicks to HiddenApp

Build a sequence of steps in a window and run it in a loop, as many times as you want — right away, at a set time or when you press a trigger.

Clicks, keys and text

Mark points by clicking the window preview, add keys (with Ctrl, Alt and Shift) or a whole text to type — with Enter at the end, if you want.

Schedule and trigger

Start by itself at 2 PM, every day or once. Or leave it waiting for a trigger: a key or mouse button that runs the macro when you press it.

Several at once

In the background, without touching your mouse, run as many macros as you want. In real mode (real mouse and keyboard), one at a time.

⚠️ Many online games forbid macros and auto clickers in their terms of service, and anti-cheat systems may ban the account. Check the game rules before using it.

How it works

No installation: it is a single file. Windows asks for administrator permission, which is required to change the firewall.

Download and open

Download HiddenApp.exe and open it. It also shows up as an icon next to the clock.

Pick the window

Select it in the list (with preview) or use "Select manually" and click the window you want.

Block or allow

One click cuts the program's internet; another gives it back. That simple.

Download

Windows 10 or 11 (64-bit). No need to install .NET or anything besides the file.

Download HiddenApp.exe All versions and release notes

Always download from this site or the official GitHub. Every version includes HiddenApp.exe.sha256 so you can verify the file is the original.

"Windows protected your PC"?

It is normal for new programs that don't have a paid digital signature yet — it doesn't mean there is a virus. To open it:

  1. Click More info;
  2. Click Run anyway;
  3. Confirm the administrator permission.

The code is open: anyone can check what the program does, and every version is built automatically by GitHub from it.

FAQ

The most common questions. Didn't find yours? Send a suggestion or question.

Why does the program ask for administrator rights?

Windows itself requires administrator permission to create and remove Windows Firewall rules. Without it, a program's internet can't be blocked.

Does blocking a program block all of its windows?

Yes. Windows controls internet access per program, not per window. To leave only one window without internet, use the "blockable copy": it opens another instance of the program with its own block.

Does the block remain after I close HiddenApp?

Yes. The rule stays in Windows Firewall until you allow the program again — even after restarting the computer.

Does HiddenApp collect my data?

No. There is no telemetry, advertising or account. It only checks GitHub for new versions. See the privacy policy.

My antivirus complained. What now?

Programs that change the firewall and simulate clicks are sometimes mistaken for threats, especially without a digital signature. Make sure you downloaded from here or the official GitHub and, if you want, verify the file with the version's .sha256. If in doubt, open a report on GitHub.

How do I uninstall it?

In the program, go to Updates ▾ → Uninstall (remove everything from the computer). It removes the firewall rules, the copies and the start with Windows. Then just delete HiddenApp.exe.
